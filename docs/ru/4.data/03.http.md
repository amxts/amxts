title: HTTP

`fetch` отправляет HTTP-запрос из плагина — так же, как в браузере, — и
возвращает промис ответа:

```ts
import { fetch } from "@amxts/core/http";

server.addCommand("/weather", async (player) => {
	const response = await fetch("https://wttr.in/?format=3");
	if (!response.ok) return print(player, `HTTP ${response.status}`);
	print(player, response.text);
});
```

Он работает через [easy_http](https://github.com/Next21Team/AmxxEasyHttp) —
модуль AMX Mod X, который должен стоять на сервере: положите его в
`addons/amxmodx/modules` и впишите в `modules.ini`. `fetch` идёт в комплекте
с amxts; импортируйте его из `@amxts/core/http`.

## Запросы

```ts
import { fetch } from "@amxts/core/http";

fetch("https://example.com/api/report", {
	method: "POST",
	body: `{"map":"${server.map}"}`,
	headers: [["Content-Type", "application/json"]],
});
```

| Настройка | Значение |
| --- | --- |
| `method` | `"GET"` (по умолчанию), `"POST"`, `"PUT"`, `"PATCH"` или `"DELETE"` |
| `body` | текст, который уходит с запросом, например JSON |
| `headers` | заголовки парами: `[["Authorization", "Bearer abc"]]` |
| `signal` | `AbortSignal`, который отменяет запрос |

## Ответ

- `response.status` — HTTP-код, `response.ok` равно `true` для кода 2xx, а
  `response.text` — всё тело ответа, какой бы длины оно ни было.
- 404 или 500 — это ответ, как в браузере: проверяйте `response.ok`.
- Промис отклоняется, когда ответа нет вовсе: нет соединения, плохой URL,
  таймаут, отменённый запрос или на сервере нет easy_http.
- Ответ всегда приходит на одном из следующих кадров сервера, никогда —
  внутри самого вызова `fetch`.

```ts
import { fetch } from "@amxts/core/http";

fetch("https://example.com/api/stats")
	.then((response) => {
		if (!response.ok) return console.log(`HTTP ${response.status}`);
		console.log(response.text);
	})
	.catch((error) => console.log(`нет ответа: ${error.message}`));
```

## Отмена

`signal` отменяет запрос, и промис отклоняется с ошибкой `AbortError` — или
`TimeoutError` для `AbortSignal.timeout(ms)`:

```ts
const response = await fetch(url, { signal: AbortSignal.timeout(5000) });   // сдаться через 5 с
```

В async-обработчике команды или события про игрока запрос отменяется сам,
когда игрок уходит ([async](../2.core/04.async.md#когда-игрок-уходит)).

## Без easy_http

Сервер без easy_http не падает на отсутствующем нативе. Каждый `fetch`
пишет в консоль сервера одну строку,
`fetch(<url>): the easy_http module is not loaded - add it to modules.ini`,
и промис отклоняется.
