title: HTTP
---

`fetch` sends an HTTP request from a plugin, the way it does in the browser,
and returns a promise of the response:

```ts
import { fetch } from "@amxts/core/http";

server.addCommand("/weather", async ({ player }) => {
	const response = await fetch("https://wttr.in/?format=3");
	if (!response.ok) return print(player, `HTTP ${response.status}`);
	print(player, response.text);
});
```

It works over [easy_http](https://github.com/Next21Team/AmxxEasyHttp), an
AMX Mod X module the server has to run: put it in `addons/amxmodx/modules`
and add it to `modules.ini`. `fetch` comes with amxts; import it from
`@amxts/core/http`.

## Requests

```ts
import { fetch } from "@amxts/core/http";

fetch("https://example.com/api/report", {
	method: "POST",
	body: `{"map":"${server.map}"}`,
	headers: [["Content-Type", "application/json"]],
});
```

| Option | Meaning |
| --- | --- |
| `method` | `"GET"` (the default), `"POST"`, `"PUT"`, `"PATCH"` or `"DELETE"` |
| `body` | the text sent with the request, such as JSON |
| `headers` | the headers, as pairs: `[["Authorization", "Bearer abc"]]` |
| `signal` | an `AbortSignal` that cancels the request |

## The response

- `response.status` is the HTTP code, `response.ok` is `true` for a 2xx one,
  and `response.text` is the whole body, however long.
- A 404 or a 500 is a response, as in the browser: check `response.ok`.
- The promise is rejected when there is no response at all: no connection, a
  bad URL, a timeout, a cancelled request, or no easy_http on the server.
- The response always arrives on a later server frame, never inside the
  `fetch` call itself.

```ts
import { fetch } from "@amxts/core/http";

fetch("https://example.com/api/stats")
	.then((response) => {
		if (!response.ok) return console.log(`HTTP ${response.status}`);
		console.log(response.text);
	})
	.catch((error) => console.log(`no answer: ${error.message}`));
```

## Cancelling

`signal` cancels the request, and the promise is rejected with an error
named `AbortError` - `TimeoutError` for `AbortSignal.timeout(ms)`:

```ts
const response = await fetch(url, { signal: AbortSignal.timeout(5000) });   // give up after 5 s
```

In an async command handler or a listener of an event about a player, the
player leaving cancels the request by itself
([async](../2.core/04.async.md#when-the-player-leaves)).

## Without easy_http

A server without easy_http does not fail on a missing native. Each
`fetch` writes one line to the server console,
`fetch(<url>): the easy_http module is not loaded - add it to modules.ini`,
and the promise is rejected.
