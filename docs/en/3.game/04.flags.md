---
title: Flags
---

Some game data is a set of on/off flags: which buttons a player holds, which
parts of the HUD are hidden, whether an entity is on the ground. In a plugin
such a set is an array of names:

```ts
function hideMoney(player: Player) {
	player.hideHud = ["Money", "Timer"];                         // set exactly these
	player.hideHud.push("Flashlight");                           // add one
	const hidden = player.hideHud.includes("Money");             // check one
	player.hideHud = player.hideHud.filter((f) => f != "Money"); // remove one
	player.hideHud = [];                                         // clear all

	const jumping = player.buttons.includes("Jump");
	const onGround = player.flags.includes("OnGround");
	console.log(`${hidden} ${jumping} ${onGround}`);
}
```

The names are a closed list: the editor suggests them and rejects a typo with
`Type '"Mony"' is not assignable to type 'HideHud'. Did you mean '"Money"'?`

- **Reading** gives an array of the flags that are on, in a fixed order -
  not the order they were added in.
- **Assigning** an array sets exactly those flags.
- **`push`** turns one more flag on in the game at once.
- **To turn a flag off**, assign a filtered array. `pop`, `splice` and the
  other array methods change only the array you hold, not the game.

## Flag properties

| Property | On | Names |
| --- | --- | --- |
| `flags` | `Entity` | `EntityFlag`: `"OnGround"`, `"Client"`, `"InWater"`, `"Fly"`, `"Ducking"`, `"FakeClient"`, `"Frozen"`, `"GodMode"`, … |
| `effects` | `Entity` | `Effect`: `"NoDraw"`, `"DimLight"`, `"BrightLight"`, `"MuzzleFlash"`, … |
| `buttons`, `oldButtons` | `Entity` | `Button`: `"Attack"`, `"Attack2"`, `"Jump"`, `"Duck"`, `"Forward"`, `"Back"`, `"Use"`, `"Reload"`, `"Score"`, … |
| `weapons` | `Entity` | `WeaponKind`: `"knife"`, `"usp"`, `"ak47"`, … - the weapons a player carries, as `weapon.kind` names them |
| `buttonLast`, `buttonPressed`, `buttonReleased` | `Player` | `Button`: what was held the frame before, what was pressed and what was let go this frame |
| `hideHud`, `clientHideHud` | `Player` | `HideHud`: `"Weapons"`, `"Flashlight"`, `"All"`, `"Health"`, `"Timer"`, `"Money"`, `"Crosshair"`, `"ObserverCrosshair"` |
| `damageType` | `Player` | `Damage`: `"Fall"`, `"Burn"`, `"Freeze"`, `"Bullet"`, `"Blast"`, … |
| `physicsFlags` | `Player` | `PhysicsFlag`: `"OnLadder"`, `"OnTrain"`, `"OnBarnacle"`, `"Ducking"`, `"Using"`, `"Observer"` |
| `weaponState` | `Weapon` | `WeaponState`: `"UspSilenced"`, `"Glock18Burst"`, `"M4a1Silenced"`, `"EliteLeft"`, `"FamasBurst"`, `"ShieldDrawn"` |

The types are exported from `~/facade`, for a parameter of your own:
`function press(player: Player, button: Button)`. Admin rights are an array of
names too: `player.access`, of the type `Access` ([commands](../2.core/01.plugin.md#commands)).

Assigning `weapons` changes only the list, not what the player carries: to
give a weapon, `player.give("weapon_ak47")`
([Players](02.players.md#actions)).

`hideHud` is what the game sends to the player's client on its next frame. To
hide parts of the HUD at once, use `player.screen.hideHud(["Money"])`
([Players](02.players.md)).
